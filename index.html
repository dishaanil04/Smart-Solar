Smart Solar

Predictive Maintenance in Solar Power Systems

About Objectives Features Results Future Scope

Project Overview

ML-based system that monitors solar PV data, detects anomalies using Isolation Forest, and predicts failures using Random Forest.

Problem Statement

Solar PV systems face inverter faults, shading, and degradation. This system predicts faults before they occur.

Key Features

  • Real-time anomaly detection
  • Machine Learning prediction
  • Power drop visualization
  • Cloud-ready deployment

Results

Isolation Forest detected anomalies successfully. Random Forest achieved ~65% accuracy.

Future Scope

  • Live SCADA integration
  • Deep Learning models
  • Interactive dashboards
  • Weather data integration
